# Klei

Een eenvoudige mobile-first React-webapp voor het bijhouden van keramiek- en pottenbakprojecten.

## Functionaliteit

- Projecten aanmaken, bekijken, bewerken en verwijderen
- Gegevens vastleggen over basisinformatie, klei, glazuur, stook en resultaat
- Lokale opslag via `localStorage`
- Geen login, backend of database
- Interface in het Nederlands

## Lokaal draaien

```bash
npm install
npm run dev
```

Open daarna de lokale URL die Vite toont.

## Build

```bash
npm run build
```

De statische build staat daarna in `dist/`.
